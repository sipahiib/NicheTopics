# Is AI Killing Graphic Design?

An English 16:9 documentary-style social video built with Remotion. The composition uses original motion graphics, burned-in word-highlight captions, and Microsoft Edge TTS (`en-GB-RyanNeural`, `-2%`).

## Commands

- `npm run voiceover` — regenerate narration, captions, timings, and the local score.
- `npm run dev` — open Remotion Studio.
- `npm run lint` — run ESLint and TypeScript checks.
- `npm run render` — render the 1920×1080 MP4 master.
- `npm run render:poster` — render the 1280×720 poster.

Rendered audio/video files remain local and are ignored by Git.
